多くの優れたCLIツールと同様に、GitHub Copilot CLIにも、操作に使えるスラッシュコマンドが数多く用意されています。コマンドを使うと、高度な機能、内部情報、追加の構成オプションを利用できます。これまでに `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などを使いました。ここでは、ほかの便利なコマンドをいくつか確認しましょう。

このレッスンでは、次のことを行います。

- `/context` と `/compact` を使い、Copilotが会話のコンテキストをどのように管理するかを確認します。
- `/model` を使い、利用できるモデルを確認します。
- `/share` でセッションをエクスポートまたは共有する方法を学びます。
- 並行作業、ワークツリー、クラウドエージェントへの委任に使えるオプションのコマンドを確認します。

## シナリオ

CLIの中心となるワークフローをひととおり確認しました。ここでは、コンテキストの管理、モデルの切り替え、セッションの共有、オプションでの[Copilotクラウドエージェントへの委任][about-cloud-agent]など、さらにいくつかの機能を見てみましょう。

## Copilot CLIのコンテキストを確認する

規模の大きいタスクや複雑なタスクに取り組むと、モデルの最大コンテキストウィンドウに達することがあります。Copilot CLIは必要に応じて会話を自動的に圧縮します。また、スラッシュコマンドを使えば、自分で確認したり圧縮したりできます。

1. Codespaceに戻り、Copilot CLIがまだ開いていない場合は、リポジトリのルートから起動します。
2. 次のコマンドを入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム指示、ツール、メッセージ、空き領域にコンテキストがどのように配分されているかを確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を入力し、結果を比較します。会話がすでに短い場合は、大きな違いが見られないことがあります。

> [!NOTE]
> コンテキストウィンドウが埋まると、Copilot CLIは自動的にコンテキストを圧縮します。自分のタイミングで圧縮する場合は `/compact` を使います。関係のない別のタスクに切り替えて新しい会話を始める場合は、`/clear` または `/new` を使います。

## モデルを選ぶ

モデルごとに得意分野が異なり、開発者によって好みも異なります。Copilot CLIでは、利用できるモデルを一覧表示し、使用するモデルを選択できます。

1. 次のコマンドを入力します。

   ```plaintext
   /model
   ```

2. 利用できるモデルと使用量に関する情報を確認します。
3. 現在のモデルを維持するか、別のモデルを選ぶか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで協力し、得た知見を共有すると、AIツールをより活用できるようになります。`/share` コマンドを使うと、セッションをMarkdownファイルまたはHTMLファイルにエクスポートしたり、共有リンクを作成したり、GitHub gistとして公開したりできます。

1. `/help` を入力し、インストール済みのバージョンで利用できる `/share` のオプションを確認します。
2. セッションを共有する場合は、ローカルのMarkdownファイルにエクスポートする `/share file` など、適切な保存先を選びます。
3. エクスポートした内容を、誰かに送ったり公開したりする前に確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれる場合があります。

リンクやgistの公開は任意です。チームが共有を意図していないリポジトリや会話の内容は公開しないでください。

## オプション: 作業を拡張または委任する

ワークショップの中心となる内容は以上です。Copilot CLIには、規模の大きなタスクに使えるコマンドもあります。

- `/fleet` を使うと、独立したサブタスクをサブエージェントに分割し、並行して実行できます。
- `/worktree` を使うと、別のタスク用に隔離されたGitワークツリーを作成できます。
- `/delegate` を使うと、タスクをCopilotクラウドエージェントに送り、非同期で処理できます。

これらのコマンドを実行すると、追加のワークツリーやリモート作業が発生する場合があるため、オプション扱いです。試すときは、範囲を明確にした新しいタスクから始め、通常のワークフローに沿って結果を確認してください。非同期エージェントの作業について詳しく知りたい場合は、[クラウドエージェントのワークショップ][cloud-workshop]に進んでください。

- `/context` と `/compact` を使い、Copilotが会話のコンテキストをどのように管理するかを確認しました。
- `/model` を使い、利用できるモデルを確認しました。
- `/share` でセッションをエクスポートまたは共有する方法を学びました。
- 並行作業、ワークツリー、クラウドエージェントへの委任に使えるオプションのコマンドを確認しました。

利用できるスラッシュコマンドはほかにもあります。Copilot CLIでできることをさらに試してみましょう。最後に、[学んだことを振り返り][next-lesson]、次の学習方法を確認します。
