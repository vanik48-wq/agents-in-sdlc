O **[agente na nuvem do GitHub Copilot](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** permite que o GitHub Copilot trabalhe de forma assíncrona na nuvem. Você atribui o trabalho no GitHub e o agente na nuvem o executa em segundo plano — explorando o repositório, fazendo alterações e abrindo um pull request — enquanto você pode se dedicar a outras tarefas.

Ao longo destes exercícios, você adicionará instruções personalizadas que o agente na nuvem seguirá; depois, atribuirá uma issue do GitHub e deixará que ele implemente o trabalho. Você revisará e usará agentes personalizados para orientar a abordagem, monitorará e conduzirá sessões no painel de agentes e, por fim, revisará os pull requests do agente e iterará nos resultados.

## Pré-requisitos

Antes de participar deste workshop, verifique se você tem:

- [ ] Uma conta do GitHub com um plano ativo **Copilot Student, Pro, Pro+, Business ou Enterprise**
- [ ] O agente na nuvem do Copilot habilitado para sua conta ou organização

> [!TIP]
> Não tem um plano pago? Estudantes com status verificado podem obter o GitHub Copilot gratuitamente pelo [GitHub Education][callout-student-plan-education]. O plano **Copilot Student** inclui o agente, MCP, revisão de código e os recursos do Copilot CLI usados neste workshop — assim, você pode concluir todo o percurso.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> O agente na nuvem está disponível nos planos **Copilot Student, Pro, Pro+, Business e Enterprise** — em todos, exceto no Copilot Free. No Copilot Business ou Enterprise, um administrador precisa habilitar o recurso para a organização.

> [!NOTE]
> Este percurso não aborda MCP. Para explorar o uso de servidores MCP com o Copilot, consulte o [percurso do CLI][cli-harness] ou o [percurso do VS Code][vscode-harness].
