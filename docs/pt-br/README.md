Escolha um workshop com base no que você quer aprender e no nível de aprofundamento desejado. **Primeiros passos** oferece uma introdução guiada ao GitHub Copilot, enquanto **Desenvolvimento no mundo real** usa um aplicativo completo e um backlog de equipe para praticar fluxos de trabalho voltados à produção.

## Primeiros passos

Comece com uma experiência guiada e focada que apresenta os principais recursos de um produto do GitHub Copilot sem exigir uma base de código existente.

### [Tour do aplicativo GitHub Copilot][first-steps-app]

Crie um Space Quiz a partir de uma pasta vazia, publique-o no GitHub, implemente uma issue, conclua uma revisão do Copilot, agende uma automação e explore um fluxo de trabalho com Canvas.

### [Primeiros passos com o GitHub Copilot CLI][first-steps-cli]

Crie o mesmo Space Quiz pelo terminal, revise diffs, execute sessões paralelas em worktrees, planeje antes de editar e crie, mescle e delegue pull requests sem sair do shell.

### [Primeiros passos com o Visual Studio Code][first-steps-vscode]

Crie o Space Quiz no VS Code, teste-o no navegador integrado, publique-o com o Source Control, trabalhe com issues e pull requests pelas ferramentas do GitHub e transfira o trabalho para uma sessão na nuvem.

## Desenvolvimento no mundo real

Pratique o GitHub Copilot em um ciclo de vida realista de desenvolvimento de software usando o aplicativo e o backlog do Tailspin Toys. Escolha o ambiente em que quer trabalhar e, em seguida, planeje, crie, teste, revise e entregue mudanças significativas.

### [Explore os workshops de desenvolvimento no mundo real][real-world-development]

Escolha entre o GitHub Copilot CLI, o aplicativo GitHub Copilot, o agente na nuvem do GitHub Copilot ou o Visual Studio Code.

> [!CAUTION]
> O GitHub Copilot é probabilístico, não determinístico. Por isso, o código exato e os arquivos alterados podem variar em relação aos exemplos. Pequenas diferenças são esperadas.
>
> Se algo parecer quebrado ou não funcionar corretamente durante um workshop conduzido por instrutor, peça ajuda a um mentor.
