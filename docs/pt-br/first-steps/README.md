Os workshops de primeiros passos são introduções guiadas que ajudam você a explorar o GitHub Copilot sem exigir um aplicativo existente ou um cenário detalhado de desenvolvimento. Cada workshop começa de forma simples, apresenta o produto durante o uso e acompanha você por um fluxo de trabalho completo.

Todos os workshops criam o mesmo Space Quiz a partir de uma pasta vazia. Assim, você pode escolher a ferramenta que quer aprender ou concluir mais de um workshop para comparar como cada uma funciona.

> [!NOTE]
> Estes workshops foram criados por [James Montemagno][james] e adaptados de [First Steps with GitHub Copilot][source-lab], disponível sob a [licença MIT][source-license].

## Workshops

### [Tour do aplicativo GitHub Copilot][copilot-app]

Crie um Space Quiz colorido a partir de uma pasta vazia e percorra o ciclo de desenvolvimento: criar, aprimorar, testar, registrar instruções do projeto, publicar, planejar o trabalho, implementar issues, revisar e mesclar um pull request, automatizar tarefas recorrentes e explorar uma extensão com Canvas.

### [Primeiros passos com o GitHub Copilot CLI][copilot-cli]

Aprenda o fluxo de trabalho centrado no terminal: crie e revise diffs antes de qualquer gravação pelo Git, execute sessões lado a lado em worktrees, planeje antes de editar, gerencie o contexto e, em seguida, crie, mescle e delegue trabalho sem sair do shell.

### [Primeiros passos com o Visual Studio Code][vscode]

Use o fluxo de trabalho do editor: crie em um workspace, aprimore elementos no navegador integrado, inspecione o contexto, teste antes de qualquer gravação pelo Git, planeje antes de editar e use as ferramentas do GitHub para gerenciar issues, pull requests e sessões na nuvem sem sair do VS Code.
